# 🗳️ 정당별로 특정 이슈에 어떤 스탠스를 갖고 있는지 LLM 없이 분석하는 법

정치 담론 분석을 하다가 직면한 문제들은 다음과 같았습니다.

> * "부동산 관련 이슈에 대해 정당 A와 B는 각각 어떤 태도를 보일까?"
> * "검찰개혁, 복지, 안보 같은 주제에서 정당별 프레임은 어떻게 다를까?"
> * "정당마다 강조하는 키워드의 차이가 뭘까?"

이런 질문은 단순히 "많이 쓰는 단어" 수준을 넘어서, **정당별로 어떤 스탠스를 가지고 있는지**를 알고 싶었습니다.
이 글에서는 LLM 없이 이 문제를 해결하기 위해 제가 시도했던 **정당별 이슈 스탠스 분석 방법 3가지를 실용 위주로** 소개합니다.

---

## 🧩 목표 정의: 표현 vs 스탠스

| 분석 수준   | 설명                               | 예시                            |
| ------- | -------------------------------- | ----------------------------- |
| 단어 빈도   | 어떤 단어가 자주 쓰였는가                   | 민주당: "복지", 국민의힘: "시장"         |
| 표현 차이   | 같은 주제에서 서로 다른 표현을 쓰는가            | 민주당: "서민 주거", 국민의힘: "공급 확대"   |
| **스탠스** | 정당이 그 이슈에 대해 찬성/반대/중립 중 어디에 가까운가 | 부동산 → 민주당: 규제 강화, 국민의힘: 규제 완화 |

---

## 1️⃣ BERTopic으로 토픽을 먼저 나눈다

[BERTopic](https://maartengr.github.io/BERTopic/)은 문장 단위에서 주요 주제를 찾아내는 토픽 모델링 도구입니다. 일반적인 LDA보다도 더 세밀한 주제를 찾을 수 있고, 무엇보다도 문장 단위 분석에 최적화되어 있습니다.

### ✅ 분석 흐름

1. 정당별 문장을 수집 (기사, 논평, SNS 등)
2. 문장 전처리 (띄어쓰기, 불용어 제거 등)
3. BERTopic으로 전체 문서에서 토픽 추출
4. 각 문장에 토픽 레이블 부여
5. 각 토픽 내에서 **정당별 문장**을 분리

### 💡 예시

\| 토픽 13 – “부동산” 관련 문장 |
\|--------|-----------------------------|
\| 더불어민주당 | “서민 주거 안정을 위한 공공주택 확대가 필요하다” |
\| 국민의힘 | “과도한 규제가 민간 공급을 막고 있다” |

---

## 2️⃣ 정당별 표현 비교 (프레이밍 차이)

같은 토픽 내에서도 **어떤 단어를 사용하는지**가 프레이밍과 스탠스를 나누는 핵심입니다.
이를 위해 사용할 수 있는 도구는 다음과 같습니다:

### ✅ TF-IDF / n-gram 차이 비교

* 각 정당별로 토픽에 속한 문장을 하나의 덩어리로 보고
* `TfidfVectorizer`로 가장 특이한 단어/표현 추출

```python
from sklearn.feature_extraction.text import TfidfVectorizer
tfidf = TfidfVectorizer(ngram_range=(1,3), max_features=1000)
tfidf_matrix = tfidf.fit_transform([민주당_문장, 국민의힘_문장])
```

* 이 결과로 나온 **상위 표현**을 비교해 보면,

  * 민주당은 "공공임대", "서민 보호"
  * 국민의힘은 "공급 확대", "시장 자율"
* 이렇게 "프레임 차이"가 드러나기 시작합니다.

---

## 3️⃣ 같은 토픽에서 정당 간 표현 차이 자동화

정당 간 차이를 수치화하거나 자동으로 비교하려면 다음 방법도 활용할 수 있습니다:

### ✅ Contrastive Keyword 추출

* 같은 토픽 안에서, 두 정당 간에 **상대적으로 많이 쓰이는 단어**만 추출합니다.
* [textacy](https://textacy.readthedocs.io/)의 JSDivergence, 또는 직접 `freq_diff = P(dem) - P(con)`로 표현 가능
* 이 과정을 통해 **중복되면서도 방향성이 다른 표현**을 강조할 수 있음

---

## 🔍 고도화: stance classification?

더 나아가고 싶다면, **스탠스 분류 모델을 훈련**하는 것도 한 방법입니다.

### 예:

```json
{ "text": "서민 주거를 위해 정부가 개입해야 한다", "stance": "찬성" }
{ "text": "규제가 시장을 망친다", "stance": "반대" }
```

이런 데이터셋을 학습한 모델은 **정당별 문장을 자동으로 '찬성/반대/중립'으로 분류**해 줄 수 있습니다.
이 방식은 정확도가 높지만, 라벨링 비용이 든다는 단점이 있습니다.

---

## 📊 시각화 예시

| 토픽   | 정당   | 대표 표현 (스탠스 유추)                |
| ---- | ---- | ----------------------------- |
| 부동산  | 국민의힘 | "규제 완화", "시장 자율", "민간 활성화"    |
| 부동산  | 민주당  | "서민 주거", "공공임대 확대", "분양가 상한제" |
| 검찰개혁 | 민주당  | "검찰 권한 축소", "수사권 조정"          |
| 검찰개혁 | 국민의힘 | "정치 탄압 수단", "수사 독립"           |

→ **이 표만으로도 정당별 스탠스/프레이밍 차이를 한눈에 볼 수 있습니다.**

## 🧪 마무리: 전체 파이프라인 요약

```text
1. 문장 수집 및 전처리
2. BERTopic으로 토픽 분류
3. 토픽별로 문장 정당별 분리
4. TF-IDF or KeyBERT로 정당별 대표 표현 추출
5. 표현 차이로 스탠스 추론 or 분류
```
