## Transformer 기반인데 왜 이렇게 다를까 – BERT와 GPT 비교

Transformer 구조만 봤을 때는 인코더와 디코더로만 나뉘는데, BERT와 GPT는 둘 다 Transformer 기반이라고 알려져 있다. 하지만 실제로는 꽤 다른 설계 철학을 가지고 있다.

처음엔 나도 그냥 “둘 다 Transformer 쓰는 거잖아?”라고 생각했는데, 이걸 직접 뜯어보니 **attention을 다루는 방식도 다르고**, **학습 방향성과 목적 자체**도 완전히 달랐다. 이번 글에서는 이 두 모델이 어떤 구조를 가지고 있고, 어떤 방식으로 학습되고 있는지를 비교해봤다.

---

### 1. Transformer 기본 구조 복습

Transformer는 크게 \*\*인코더(Encoder)\*\*와 \*\*디코더(Decoder)\*\*로 나뉜다.

* 인코더는 입력 문장을 받아 **정보를 요약한 벡터로 인코딩**하는 역할
* 디코더는 그 정보를 바탕으로 **출력 문장을 생성**하는 역할

여기서 핵심 컴포넌트는 self-attention이다. 입력 토큰들이 서로를 얼마나 참조해야 하는지를 계산해서, 각 토큰의 의미를 문맥에 맞게 업데이트한다.

그런데 BERT와 GPT는 이 기본 구조 중 **어느 부분만을 사용하느냐**에 따라 성격이 완전히 달라졌다.

---

### 2. BERT: 인코더만 쓰는 구조

BERT는 Transformer의 **인코더 부분만** 사용하는 구조다. 전체 문장을 한 번에 받아서, 양방향 문맥을 전부 고려한 뒤에 각 단어의 의미를 정교하게 인코딩한다.

#### 🔍 Attention 방식

BERT는 **bidirectional self-attention**을 쓴다.
즉, 한 단어를 인코딩할 때 **좌우 모든 단어를 동시에 참조**한다.
예를 들어 "The cat is on the mat"라는 문장에서 "is"를 인코딩할 때, "The", "cat", "on", "the", "mat" 전부를 함께 보는 것이다.

이게 가능한 이유는 BERT가 **전체 문장을 한꺼번에** 받아들이고, **미리 예측할 게 없는 상태에서** 학습하기 때문이다.

#### 🧠 학습 방식

BERT는 **Masked Language Modeling (MLM)** 방식으로 학습된다.
문장 안에 랜덤하게 몇 개의 단어를 \[MASK] 처리하고, 그 마스크된 단어가 무엇인지 맞추는 방식이다.

예:
입력 → "The cat is on the \[MASK]"
예측 → "mat"

이 방식은 문장의 앞뒤를 모두 고려해 정답을 예측할 수 있게 한다.
덕분에 문장 내 단어들 간의 정교한 관계를 잘 파악하지만, 단점도 있다.
바로, **문장을 생성하는 데는 약하다**는 점이다. 마스크를 예측하는 데 최적화돼 있어서, 순차적인 문장 생성에는 바로 사용할 수 없다.

---

### 3. GPT: 디코더만 쓰는 구조

반대로 GPT는 Transformer의 **디코더 부분만** 사용하는 구조다. 입력 문장을 한 단어씩 차례로 넣고, 다음에 나올 단어를 예측해 문장을 생성한다.

#### 🔍 Attention 방식

GPT는 **causal (unidirectional) attention**을 사용한다.
즉, 현재 토큰이 **이전 토큰들만 참조**할 수 있게 마스킹이 걸려 있다.
예를 들어 "The cat is"라는 문장에서 "is"를 인코딩할 때, "The", "cat"만 볼 수 있고, 뒤쪽 단어는 전혀 보지 못한다.

이 마스킹이 GPT의 핵심이다.
문장을 순차적으로 생성해내는 데 최적화돼 있기 때문이다.

#### 🧠 학습 방식

GPT는 **Autoregressive Language Modeling** 방식으로 학습된다.
매 순간 다음 단어를 예측하는 방식이다.

예:
입력 → "The cat is on the"
정답 → "mat"

이걸 반복하면서 문장을 한 단어씩 생성해 나간다.
학습 자체가 문장 생성을 목표로 되어 있기 때문에, **텍스트 생성에 매우 강하다.**
대신 양방향 문맥을 고려하지 못해, 문장 내 의미 관계를 세밀하게 잡아내는 데는 BERT보다 약한 면도 있다.

---

### 4. 요약: 구조, attention, 학습 목적 비교

| 항목           | BERT               | GPT                             |
| ------------ | ------------------ | ------------------------------- |
| 사용 구조        | Transformer 인코더만   | Transformer 디코더만                |
| Attention 방식 | Bidirectional      | Unidirectional (Causal Masking) |
| 학습 목적        | Masked 단어 예측 (MLM) | 다음 단어 예측 (Autoregressive)       |
| 문장 이해        | 강함                 | 비교적 약함                          |
| 문장 생성        | 약함                 | 강함                              |

---

### 5. 그래서 같이 쓰면 좋다?

바로 이 이유 때문에 **BERT와 GPT를 함께 사용하는 시도**가 나온다.
BERT로 문장을 세밀하게 인코딩하고, 그 정보를 GPT로 넘겨서 자연스럽게 문장을 생성하면, 두 모델의 장점을 모두 활용할 수 있게 된다.

--- 

지금까지 BERT와 GPT가 Transformer 기반이라는 공통점에도 불구하고, 구조적으로 상당히 다른 방향을 취하고 있다는 내용을 정리했다.
이제는는 그 구조 차이의 핵심이라 할 수 있는 **Self-Attention의 사용 방식**, 특히 **어떻게 Masking을 설정하고, 어떤 정보 흐름을 제한하거나 열어주는지**를 비교해보려고 한다.

---

### 1. Self-Attention, 다시 짚고 넘어가기

Transformer에서 Self-Attention은 각 토큰이 다른 모든 토큰을 얼마나 참고할지를 계산하는 과정이다.
그런데 이 과정에서 모든 토큰을 다 참고해도 되는지, 아니면 일부만 봐야 하는지가 모델의 목적에 따라 달라진다.

이걸 제어하는 게 바로 **Attention Mask**다.

---

### 2. BERT의 Attention: 양방향으로 열린 정보 흐름

BERT는 문장을 통째로 받아서, 중간중간 일부 단어만 마스킹하고 나머지 단어들을 전부 활용해 문맥을 이해하는 구조다.

즉, 한 단어를 인코딩할 때 **문장 전체의 정보를 모두 참고할 수 있도록 허용**한다.
이 구조를 가능하게 하는 이유는, BERT가 학습할 때 **정답(마스크된 단어)이 어떤 위치에 있을지 미리 모르기 때문**이다.

#### 📌 예시:

```python
sentence = "The [MASK] is on the mat"
```

이 문장에서 `[MASK]`에 들어갈 단어를 예측할 때, "is", "on", "the", "mat"을 전부 참고하는 게 자연스럽다.
이런 구조 덕분에 BERT는 매우 정교한 문맥 이해를 할 수 있다.

#### 🧠 Attention Mask 구조

* 마스킹은 단어 자체를 가리는 데 쓰이며,
* Attention은 **모든 위치를 다 볼 수 있게 열려 있다.**

그래서 BERT의 Attention Mask는 아래처럼 열린 구조를 가진다 (시각화 예시 포함 가능):

```
Query 위치 → 모든 Key 위치 참조 가능 (좌우 제한 없음)
```

---

### 3. GPT의 Attention: 시간 순서를 지키는 제한된 흐름

GPT는 문장을 생성하는 데 특화되어 있다.
그래서 학습할 때 **항상 다음 단어를 예측**하는 방식으로 학습되며, **미래 토큰을 미리 보면 안 된다.**

이걸 구현하기 위해 사용하는 게 **Causal Mask**이다.
즉, 현재 토큰은 자신보다 앞에 있는 토큰만 볼 수 있도록 마스킹을 건다.

#### 📌 예시:

```python
sentence = "The cat is on the"
```

이 상황에서 "on"을 예측할 때, "The", "cat", "is"만 참고해야 한다. "the" 뒤의 내용은 절대 보면 안 된다.

#### 🧠 Attention Mask 구조

GPT의 Attention Mask는 아래처럼 아래삼각형 형태의 마스킹이다:

```
Query 위치 → 이전 Key 위치만 참조 가능 (현재 이전만 허용)
```

|        | t0 | t1 | t2 | t3 | t4 |
| ------ | -- | -- | -- | -- | -- |
| **Q0** | ✔  |    |    |    |    |
| **Q1** | ✔  | ✔  |    |    |    |
| **Q2** | ✔  | ✔  | ✔  |    |    |
| **Q3** | ✔  | ✔  | ✔  | ✔  |    |
| **Q4** | ✔  | ✔  | ✔  | ✔  | ✔  |

이런 구조 덕분에 GPT는 **한 단어씩 생성하면서 그 앞의 정보만 가지고 다음을 예측**할 수 있다.
이게 바로 GPT가 텍스트 생성에 강한 이유다.

---

### 4. 학습 관점에서의 차이점 요약

| 항목           | BERT                                                     | GPT                                                               |
| ------------ | -------------------------------------------------------- | ----------------------------------------------------------------- |
| Attention 방향 | 양방향 (좌우 모두)                                              | 단방향 (좌측만)                                                         |
| Masking 목적   | 단어 자체를 가림 (MLM)                                          | 정보 흐름 제한 (Causal)                                                 |
| 문장 이해        | 정교함, 문맥 기반 해석                                            | 문장 생성 최적화                                                         |
| 실습 예시        | `transformers.BertModel`에서 `attention_mask`는 padding 구분용 | `transformers.GPT2Model`에서 `attention_mask` + `causal_mask` 자동 처리 |

---

### 5. 그래서 어떤 모델을 언제 써야 할까?

* 문장을 잘 **이해하고 분류**하거나, **문장 내 의미를 분석**하고 싶을 때는 → BERT 계열이 강하다.
* 텍스트를 **순차적으로 생성**하거나, **대화**, **요약**, **창작** 등의 작업에는 → GPT 계열이 적합하다.

물론 최근에는 이 두 구조를 결합한 다양한 모델들(e.g. T5, BART 등)도 등장했고, 활용도는 점점 넓어지고 있다.
