# React Native 라이프사이클 정리

React Native에서의 라이프사이클은 React의 라이프사이클과 동일하게 작동하며, **클래스형 컴포넌트**와 **함수형 컴포넌트 (React Hooks 사용)**로 나뉩니다.

## 1. 클래스형 컴포넌트의 라이프사이클

클래스형 컴포넌트에서는 React의 라이프사이클 메서드를 그대로 사용할 수 있습니다.

### 🟢 마운트 (Mount) - 컴포넌트가 처음 화면에 렌더링될 때 실행

- `constructor()`: 초기 상태(state) 및 변수 설정
- `componentDidMount()`: 컴포넌트가 화면에 나타난 후 실행 (API 호출, 이벤트 리스너 등록 등)

```jsx
class MyComponent extends React.Component {
  constructor(props) {
    super(props);
    this.state = { count: 0 };
    console.log("constructor");
  }

  componentDidMount() {
    console.log("componentDidMount");
  }

  render() {
    return <Text>Hello, World!</Text>;
  }
}
```

### 🟡 업데이트 (Update) - 상태(state) 또는 props가 변경될 때 실행

- `shouldComponentUpdate(nextProps, nextState)`: 리렌더링 여부 결정
- `componentDidUpdate(prevProps, prevState)`: 업데이트 후 실행

```jsx
class MyComponent extends React.Component {
  state = { count: 0 };

  shouldComponentUpdate(nextProps, nextState) {
    return nextState.count !== this.state.count; // count 변경 시만 업데이트
  }

  componentDidUpdate(prevProps, prevState) {
    console.log("componentDidUpdate", prevState.count, "->", this.state.count);
  }

  render() {
    return <Text>{this.state.count}</Text>;
  }
}
```

### 🔴 언마운트 (Unmount) - 컴포넌트가 화면에서 제거될 때 실행

- `componentWillUnmount()`: 정리 작업 수행 (이벤트 리스너 제거, API 요청 취소 등)

```jsx
class MyComponent extends React.Component {
  componentWillUnmount() {
    console.log("componentWillUnmount");
  }

  render() {
    return <Text>Goodbye!</Text>;
  }
}
```

## 2. 함수형 컴포넌트와 React Hooks의 라이프사이클

함수형 컴포넌트에서는 `useEffect`를 활용하여 라이프사이클을 관리합니다.

### 🟢 마운트 & 🟡 업데이트 & 🔴 언마운트

- `useEffect(() => { ... }, [])` → 마운트 시 실행 (`componentDidMount` 역할)
- `useEffect(() => { ... }, [dependencies])` → 상태 또는 props 변경 시 실행 (`componentDidUpdate` 역할)
- `useEffect(() => { return () => { ... }; }, [])` → 언마운트 시 실행 (`componentWillUnmount` 역할)

```jsx
import React, { useState, useEffect } from "react";
import { Text, Button, View } from "react-native";

const MyComponent = () => {
  const [count, setCount] = useState(0);

  useEffect(() => {
    console.log("Component Mounted");
    return () => {
      console.log("Component Unmounted");
    };
  }, []);

  useEffect(() => {
    console.log("Count Updated:", count);
  }, [count]);

  return (
    <View>
      <Text>{count}</Text>
      <Button title="Increase" onPress={() => setCount(count + 1)} />
    </View>
  );
};
```

## 3. React Native 특화 라이프사이클

React Native에서는 추가적인 라이프사이클 관리가 필요할 때가 있습니다.

### 📱 앱이 백그라운드로 전환될 때 감지 (AppState)

`AppState`를 사용하여 앱의 포그라운드/백그라운드 상태 변화를 감지할 수 있습니다.

```jsx
import React, { useEffect, useState } from "react";
import { AppState, Text } from "react-native";

const AppStateExample = () => {
  const [appState, setAppState] = useState(AppState.currentState);

  useEffect(() => {
    const subscription = AppState.addEventListener("change", (nextAppState) => {
      console.log("AppState changed to", nextAppState);
      setAppState(nextAppState);
    });

    return () => {
      subscription.remove(); // 정리
    };
  }, []);

  return <Text>Current AppState: {appState}</Text>;
};
```

### 🔍 컴포넌트가 화면에 나타날 때 감지 (useFocusEffect)

`React Navigation`의 `useFocusEffect`를 사용하면 특정 화면이 포커스를 받을 때 실행할 수 있습니다.

```jsx
import { useFocusEffect } from "@react-navigation/native";
import { useCallback } from "react";
import { Text } from "react-native";

const ScreenComponent = () => {
  useFocusEffect(
    useCallback(() => {
      console.log("Screen is focused");
      return () => {
        console.log("Screen is unfocused");
      };
    }, [])
  );

  return <Text>Screen Content</Text>;
};
```

## 4. 라이프사이클 정리

| 라이프사이클     | 클래스형 컴포넌트      | 함수형 컴포넌트                                  |
| ---------------- | ---------------------- | ------------------------------------------------ |
| 마운트 시 실행   | `componentDidMount`    | `useEffect(() => { ... }, [])`                   |
| 업데이트 시 실행 | `componentDidUpdate`   | `useEffect(() => { ... }, [dependencies])`       |
| 언마운트 시 실행 | `componentWillUnmount` | `useEffect(() => { return () => { ... }; }, [])` |

추가적으로 `AppState`와 `useFocusEffect`를 활용하면 React Native의 환경에서 더욱 효과적으로 라이프사이클을 관리할 수 있습니다.
