# 🖥️ 로컬 파일을 EC2 서버로 업로드하는 방법 정리

## ✅ 배경: 왜 이게 필요할까?

웹 서버를 운영하거나, 테스트 코드를 배포하거나, 데이터 파일을 서버에서 처리해야 할 때, **로컬 컴퓨터에 있는 파일을 EC2와 같은 원격 서버에 업로드**해야 한다.

하지만 **PuTTY 자체는 단순히 원격 접속(SSH)만 가능**할 뿐, 파일 전송 기능은 없음.
그래서 파일 전송을 위해 다른 도구들이 필요하다.

## ✅ PuTTY란?

PuTTY는 Windows 환경에서 **SSH(Secure Shell)** 접속을 위해 가장 많이 쓰이는 프로그램 중 하나다. 주로 **리눅스 서버에 원격 접속**하기 위해 사용된다.

📌 즉, "EC2에 접속해서 명령어를 입력하고 싶을 때" PuTTY를 사용한다!

### ✅ 언제 사용하는가?

| 상황                                    | 사용 여부                       |
| --------------------------------------- | ------------------------------- |
| EC2 서버에 접속하고 싶을 때             | ✅ 강력 추천                    |
| 리눅스 서버와 터미널로 작업하고 싶을 때 | ✅ 추천                         |
| 파일을 업로드/다운로드 하고 싶을 때     | ❌ PuTTY는 불가능 (WinSCP 사용) |

---

### ✅ PuTTY는 무엇을 할 수 있나?

| 작업                     | 가능 여부             |
| ------------------------ | --------------------- |
| 리눅스 명령어 실행       | ✅                    |
| 서버 설정 변경           | ✅                    |
| 웹서버 실행/중지         | ✅                    |
| Git clone 등 터미널 작업 | ✅                    |
| 파일 업로드/다운로드     | ❌ 불가 (WinSCP 필요) |

---

### ✅ 요약

- **PuTTY = 서버 원격 접속용 SSH 도구 (터미널 작업용)**
- `.pem` 키는 `.ppk`로 변환해서 사용
- 서버 파일 전송은 **WinSCP**, **pscp**, 또는 **FileZilla** 같이 사용
- Mac/Linux 사용자라면 PuTTY 필요 없이 기본 `ssh` 사용 가능

---

## ✅ EC2에 접속하는 방법

### 1. `.pem` → `.ppk` 변환 (최초 1회)

AWS EC2에서 받은 `.pem` 키 파일은 PuTTY가 바로 인식 못함 → `.ppk`로 변환해야 함

```bash
1. PuTTYgen 실행
2. Load → .pem 파일 선택
3. Save private key → .ppk로 저장
```

### 2. PuTTY로 접속

1. Host Name: `ec2-user@<EC2 퍼블릭 IP>` 또는 `ubuntu@...`
2. Port: 22
3. Connection > SSH > Auth > Private Key File: `.ppk` 파일 지정
4. Open 클릭 → 접속 성공!

---

## 📁 EC2는 컨테이너가 아님!

> EC2는 가상 머신(VM, Virtual Machine)이다.
> ❌ 컨테이너(Docker 등)와는 다름.

- **EC2**: 전체 운영체제(OS)가 깔린 가상 서버 (ex. Ubuntu 서버 전체)
- **컨테이너**: 격리된 실행 환경 (ex. Python만 돌아가는 미니 환경)

---

## 📦 로컬 → EC2로 파일 올리는 방법들

### 1. **WinSCP (GUI 추천)**

- Windows 전용 GUI 파일 전송 툴
- 드래그 앤 드롭으로 간편하게 EC2에 파일 업로드
- PuTTY 키 파일(.ppk)을 그대로 사용할 수 있음

#### 사용법:

1. WinSCP 설치
2. 파일 프로토콜: SFTP 또는 SCP
3. 호스트 이름: EC2 퍼블릭 IP
4. 사용자 이름: 보통 `ec2-user` 또는 `ubuntu`
5. 개인 키 파일: `.ppk` 파일 선택
6. 접속 후 좌측(로컬), 우측(서버) 드래그로 전송

### 2. **FileZilla (GUI, 멀티 플랫폼)**

- Windows/Mac/Linux 모두 사용 가능
- SFTP 모드로 EC2 연결 가능
- WinSCP과 거의 동일한 기능

### 3. **pscp (PuTTY용 CLI 명령어)**

- PuTTY 설치 시 같이 들어있는 커맨드라인 파일 전송 도구

```bash
pscp -i your-key.ppk localfile.txt ec2-user@<EC2-IP>:/home/ec2-user/
```

### 4. **scp (Mac/Linux/WSL에서 CLI 전송)**

```bash
scp -i ~/your-key.pem ./myfile.zip ec2-user@<EC2-IP>:/home/ec2-user/
```

- `-i`: 키 파일 경로
- `ec2-user@IP`: 로그인 정보
- `/home/ec2-user/`: 업로드할 EC2 경로

---

### 🧰 GitHub에서 EC2로 코드 다운받아 사용하는 방법

#### ✅ 1. Git 설치 (EC2 내부)

먼저 EC2에 Git이 설치돼 있어야 함.

```bash
sudo apt update
sudo apt install git -y
```

---

#### ✅ 2. GitHub에서 Repository 클론

- 공개 저장소라면:

```bash
git clone https://github.com/사용자이름/저장소이름.git
```

- 비공개 저장소라면 (토큰 사용):

```bash
git clone https://<username>:<your_token>@github.com/<username>/<repo>.git
```

---

#### ✅ 3. 특정 폴더만 받고 싶다면? (Sparse Checkout)

```bash
mkdir my-repo && cd my-repo

git init
git remote add origin https://github.com/사용자이름/저장소이름.git

git config core.sparseCheckout true
echo "원하는/폴더/경로/" >> .git/info/sparse-checkout

git pull origin main  # 또는 필요한 브랜치
```

#### ✅ 4. 이후 파일 수정 및 사용

- 클론 후 직접 코드 수정하거나
- 정적 웹 파일은 `/var/www/html/`에 복사하여 웹서비스 가능

```bash
sudo cp -r test/ /var/www/html/
```

---

#### ✅ 요약

| 목적               | 명령어                    |
| ------------------ | ------------------------- |
| 전체 프로젝트 받기 | `git clone <repo>`        |
| 비공개 Repo 받기   | 토큰 포함된 URL 사용      |
| 특정 폴더만 받기   | sparse-checkout 설정      |
| 웹으로 띄우기      | `/var/www/html/`으로 복사 |

## 🛠️ 언제 어떤 도구를 쓰면 좋을까?

| 상황                       | 추천 도구                   |
| -------------------------- | --------------------------- |
| Windows + GUI 선호         | WinSCP or FileZilla         |
| Windows + 터미널 좋아함    | `pscp`                      |
| Mac/Linux/WSL 사용자       | `scp`                       |
| GitHub로 관리하는 프로젝트 | Git 클론 후 서버에서 `pull` |

| 용어             | 설명                                    |

| WinSCP/FileZilla | 파일 전송 도구 (SCP/SFTP 지원)          |

## ✅ 결론

- PuTTY만으로는 파일 전송이 안 되므로 **WinSCP**, **FileZilla**, 또는 **scp/pscp**를 같이 써야 한다.
- EC2는 컨테이너가 아니라 전체 리눅스 서버다.
- 목적과 환경에 따라 알맞은 툴을 쓰면, 로컬 파일을 EC2에 쉽게 올릴 수 있다.
- Mac/Linux 사용자라면 PuTTY 필요 없이 기본 `ssh` 사용 가능
