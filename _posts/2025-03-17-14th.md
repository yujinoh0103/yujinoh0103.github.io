## ✅ 📌 코드 상세 분석

### 1️⃣ useState와 useEffect를 이용한 상태 관리

```tsx
const [weatherData, setWeatherData] = useState(null);
const [loading, setLoading] = useState(true);
```

- `weatherData`: API에서 가져온 날씨 정보를 저장하는 상태
- `loading`: 데이터를 불러오는 동안 `ActivityIndicator`(로딩 스피너)를 표시하기 위한 상태

### 2️⃣ useEffect를 사용하여 컴포넌트가 마운트될 때 날씨 정보 가져오기

```tsx
useEffect(() => {
  (async () => {
    // 비동기 데이터 처리 코드
  })();
}, []);
```

- `useEffect()`는 의존성 배열이 `[]`일 경우 **최초 1회 실행됨** → 컴포넌트가 마운트될 때만 실행
- 비동기 즉시 실행 함수 `(async () => {})()` 를 사용하여 내부에 `await` 가능하게 함

### 3️⃣ expo-location을 사용해 현재 위치 가져오기

```tsx
let { status } = await Location.requestForegroundPermissionsAsync();
if (status !== "granted") {
  console.error("위치 권한이 필요합니다.");
  return;
}
```

- `requestForegroundPermissionsAsync()` → 사용자에게 위치 정보 권한 요청
- 허용하지 않으면 데이터 로딩을 중단하고 에러 출력

```tsx
let loc = await Location.getCurrentPositionAsync({});
const { latitude, longitude } = loc.coords;
```

- 현재 기기의 위도, 경도 정보를 얻음 → 예시: 위도 37.5665, 경도 126.9780 (서울 기준)

### 4️⃣ OpenWeatherMap API 호출하여 날씨 데이터 가져오기

```tsx
const url = `${BASE_URL}?lat=${latitude}&lon=${longitude}&appid=${API_KEY}&units=metric&lang=kr`;
```

- `lat`, `lon`, `appid`, `units=metric`, `lang=kr`로 구성된 API 요청 URL

### 5️⃣ fetch()로 API 요청 및 JSON 파싱

```tsx
const response = await fetch(url);
if (!response.ok) throw new Error("API 요청 실패");
const json = await response.json();
```

- `fetch()`는 비동기 함수로 API를 호출
- `.ok`가 false면 오류 처리
- `await response.json()`으로 JSON 데이터 추출

```tsx
setWeatherData({
  temperature: `${json.main.temp}°C`,
  feelsLike: `${json.main.feels_like}°C`,
  weather: json.weather[0].description,
  humidity: `${json.main.humidity}%`,
  windSpeed: `${json.wind.speed}m/s`,
  city: json.name,
});
```

- API 응답값에서 필요한 데이터를 구조화하여 상태 업데이트

### 6️⃣ 데이터를 화면에 렌더링 (조건부 렌더링)

```tsx
return (
  <View>
    {loading ? (
      <ActivityIndicator size="large" color="blue" />
    ) : (
      weatherData && (
        <View>
          <Text>📍 위치: {weatherData.city}</Text>
          <Text>🌡️ 기온: {weatherData.temperature}</Text>
          <Text>🥶 체감온도: {weatherData.feelsLike}</Text>
          <Text>🌤️ 날씨: {weatherData.weather}</Text>
          <Text>💧 습도: {weatherData.humidity}</Text>
          <Text>💨 풍속: {weatherData.windSpeed}</Text>
        </View>
      )
    )}
  </View>
);
```

- 로딩 중이면 스피너, 완료되면 날씨 정보 보여줌 (삼항 연산자 + 조건부 렌더링 활용)

## 🚀 async란?

`async`는 비동기 함수를 선언하는 키워드로, 내부에서 `await`를 사용할 수 있게 해줌.

```tsx
async function fetchData() {
  const response = await fetch("https://api.example.com/data");
  const data = await response.json();
  console.log(data);
}
```

- `await`는 Promise가 해결(resolve)될 때까지 기다림
- 동기적인 코드처럼 작성 가능해서 **가독성이 좋고 유지보수에 유리함**

### ✅ useEffect에서 async 사용하는 방법

```tsx
useEffect(() => {
  (async () => {
    try {
      let { status } = await Location.requestForegroundPermissionsAsync();
      if (status !== "granted") return;

      let loc = await Location.getCurrentPositionAsync({});
      const { latitude, longitude } = loc.coords;

      const url = `${BASE_URL}?lat=${latitude}&lon=${longitude}&appid=${API_KEY}&units=metric&lang=kr`;
      const response = await fetch(url);
      if (!response.ok) throw new Error("API 요청 실패");
      const json = await response.json();

      setWeatherData({
        temperature: `${json.main.temp}°C`,
        weather: json.weather[0].description,
        city: json.name,
      });
    } catch (error) {
      console.error("❌ 날씨 데이터 가져오기 실패:", error);
    } finally {
      setLoading(false);
    }
  })();
}, []);
```

### ❌ async를 사용하지 않는 경우 (then 체인 방식)

```tsx
useEffect(() => {
  Location.requestForegroundPermissionsAsync()
    .then(({ status }) => {
      if (status !== "granted") throw new Error("위치 권한 필요");
      return Location.getCurrentPositionAsync({});
    })
    .then((loc) => {
      const { latitude, longitude } = loc.coords;
      const url = `${BASE_URL}?lat=${latitude}&lon=${longitude}&appid=${API_KEY}&units=metric&lang=kr`;
      return fetch(url);
    })
    .then((response) => {
      if (!response.ok) throw new Error("API 요청 실패");
      return response.json();
    })
    .then((json) => {
      setWeatherData({
        temperature: `${json.main.temp}°C`,
        weather: json.weather[0].description,
        city: json.name,
      });
    })
    .catch((err) => console.error("❌ 실패:", err))
    .finally(() => setLoading(false));
}, []);
```

- `then()` 방식은 연속적인 Promise 체인을 사용하며 **가독성이 떨어질 수 있음**

## 🎯 async/await 정리

| 키워드      | 설명                           |
| ----------- | ------------------------------ |
| `async`     | 비동기 함수 정의               |
| `await`     | Promise가 해결될 때까지 기다림 |
| `fetch()`   | API 요청을 보내는 비동기 함수  |
| `try/catch` | 오류 처리 구조                 |
