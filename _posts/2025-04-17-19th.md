Python과 pandas를 다루다 보면 가장 혼동되기 쉬운 부분 중 하나가 바로 `apply`, `sum`, `axis`의 관계입니다. 특히, `df.apply(sum, axis=0)` 같은 코드를 마주치면 "대체 sum은 axis를 받지도 않는데 왜 되는 거지?"라는 의문이 들 수 있습니다. 이 글에서는 그 개념을 파헤쳐보겠습니다.

## 1. pandas 객체와 메서드 구조

먼저 기본 구조를 짚고 갑시다.

- `pd.DataFrame()` → pandas에서 제공하는 **생성자** (클래스)
- `df.sum()` → DataFrame 객체(`df`)가 가진 **메서드**

이 둘은 역할이 다릅니다.

- `pd.DataFrame()`은 객체를 만드는 도구
- `df.sum()`은 만들어진 객체에 대해 어떤 동작을 수행하는 기능

쉽게 말해 붕어빵 틀(`DataFrame`)로 붕어빵을 만든 다음, 붕어빵을 먹거나 자르는 동작이 메서드(`.sum()` 등)입니다.

---

## 2. apply 함수의 구조와 axis 인자

```python
df.apply(sum, axis=0)
```

이 코드를 보자면 `sum`은 파이썬 기본 함수이고, `axis=0`은 `apply()` 함수에 전달됩니다.

즉,

- `apply()`는 DataFrame의 **열 또는 행 단위로 쪼개서**
- 쪼개진 **Series 단위로 sum()을 호출**합니다.

이 과정에서 `sum()` 함수는 **각 열(Series)**만 받아서 단순 합산을 수행하기 때문에, `axis`에 대한 정보는 알 필요도 없고 받지도 않습니다.

**중요:** `axis`는 `apply()`가 어떻게 데이터를 쪼갤지를 정하는 인자이지, `sum()`에 전달되지 않습니다.

---

## 3. Series에서의 apply

```python
df['키'].apply(sum, axis=0)  # ❌ TypeError
```

이 코드는 왜 에러가 날까요? `df['키']`는 `Series`입니다. `Series.apply(func)`는 **각 원소에 대해 함수**를 적용합니다.

즉, 내부적으로 다음과 같이 동작합니다:

```python
for val in df['키']:
    sum(val, axis=0)  # ❌ sum()은 axis를 모름 → TypeError 발생
```

따라서 이 경우에는 axis 인자를 넘기면 안 됩니다.

---

## 4. sum(x)과 x.sum()의 차이

- `sum(x)`는 파이썬 기본 함수
- `x.sum()`은 pandas 객체(`Series`, `DataFrame`)의 메서드

즉:

```python
sum(df['키'])     # → 파이썬 sum, 리스트처럼 동작
x.sum()           # → pandas 메서드로 더 다양한 기능 가능 (예: skipna, axis 등 지원)
```

# Part 2: 실전 예제로 개념 정리하기

## 1. Series에서 apply + sum 사용 시 주의

```python
# 에러 발생 코드
series = df['키']
series.apply(sum, axis=0)  # ❌ TypeError
```

이유:

- `apply`는 각 원소에 `sum(val, axis=0)`을 호출하게 되며,
- `sum()`은 axis를 받지 않기 때문입니다.

해결책:

```python
# 그냥 sum 호출하면 됨
sum(series)          # 또는
series.sum()
```

## 2. DataFrame에서 apply와 sum의 조합은 OK

```python
df[['키']].apply(sum, axis=0)  # ✅ 정상 작동
```

이유:

- `apply()`가 열 단위로 `sum()`을 호출하며,
- `sum()`은 전달된 Series 하나에 대해 총합을 구하기 때문입니다.

내부적으로 다음과 같은 구조:

```python
for col in df.columns:
    result[col] = sum(df[col])
```

## 3. 디버깅 팁: 들어가는 값 확인하기

함수를 적용할 때 무슨 값이 들어오는지 궁금하다면 이렇게 확인해보세요:

```python
def debug(x):
    print("x:", x)
    return sum(x)

df[['키']].apply(debug, axis=0)
```

출력값을 통해 `apply()`가 각 열을 하나의 Series로 넘기고 있다는 걸 알 수 있습니다.
