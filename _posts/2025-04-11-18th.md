## ✅ `map()` 함수: 반복 없이 함수 적용하기

```python
from math import pow

numbers = [1, 2, 3, 4]
arr1 = list(map(lambda x: pow(x, 2), numbers))
```

- `map(함수, iterable)`은 iterable의 요소 하나하나에 함수를 적용
- `list()`로 감싸서 결과를 리스트로 변환
- 위 코드: `numbers`의 각 요소를 제곱하여 `arr1`에 저장

📌 **반복문 없이 함수 적용 가능**한 이유는  
`map()`이 내부적으로 iterable을 순회하면서 함수를 적용하기 때문

## ✅ `*args` / `**kwargs` vs `*` 문법

### 🔹 `*args`, `**kwargs`

```python
def my_func(*args, **kwargs):
    print(args)    # 튜플
    print(kwargs)  # 딕셔너리
```

- `*args`: 위치 인자를 튜플로 묶음
- `**kwargs`: 키워드 인자를 딕셔너리로 묶음
- 변수 이름은 `args`, `kwargs`가 아니어도 됨 (ex. `*banana`, `**apple`도 OK)

### 🔹 일반 `*`의 사용

```python
a, *b, c = [1, 2, 3, 4]
# a = 1, b = [2,3], c = 4
```

- 함수 정의 외에도 할당, 리스트 언패킹 등에서 사용 가능
- `*`는 **포인터가 아님**, **묶고 풀기(unpacking)**를 위한 문법

### 📌 어디서 쓰이는지 구분해서 보면:

| 문법            | 예시                    | 설명                                            |
| --------------- | ----------------------- | ----------------------------------------------- |
| `*args`         | `def f(*args):`         | 위치 인자들을 튜플로 받음                       |
| `**kwargs`      | `def f(**kwargs):`      | 키워드 인자들을 딕셔너리로 받음                 |
| 언패킹 할 때    | `a, *b = [1, 2, 3]`     | `b = [2, 3]`처럼 리스트 등에서 나머지 값을 모음 |
| 함수 호출 시    | `f(*[1, 2])`            | 리스트를 인자로 풀어서 전달                     |
| 딕셔너리 언패킹 | `f(**{'x': 1, 'y': 2})` | 딕셔너리를 키워드 인자로 풀어서 전달            |

### 🔹 포인터처럼 "참조"가 되긴 한다?

파이썬 변수는 **값을 담는 게 아니라 객체를 가리키는 참조(reference)** 를 저장함:

```python
a = [1, 2, 3]
b = a
b[0] = 100
print(a)  # [100, 2, 3]
```

- `a`와 `b`는 같은 리스트를 참조 → 메모리 주소 개념과 비슷하지만,
- **주소를 직접 조작하거나 역참조하는 기능은 없음 (`*ptr`, `&var` 같은 것 X)**

### 🔹 진짜 포인터처럼 쓰고 싶다면?

파이썬에서는 일반적으로 포인터가 필요 없도록 설계되어 있지만,  
**리스트, 클래스, 딕셔너리 등은 mutable 객체**라서 참조처럼 작동함.  
그래서 리스트를 함수에 넘기면 원본이 바뀔 수도 있음:

```python
def modify(lst):
    lst[0] = 999

nums = [1, 2, 3]
modify(nums)
print(nums)  # [999, 2, 3]
```

---

✅ 파이썬의 `*`, `**`는 **묶기와 풀기(unpacking)** 문법이지,

❌ 메모리 주소를 직접 다루는 **포인터 문법이 아니다!**

## ✅ `del` 키워드

```python
fruits = ["apple", "banana", "cherry"]
del fruits[fruits.index("cherry")]
```

- `del`은 **리스트 요소, 변수, 객체 속성**을 삭제하는 **statement**
- `del` 자체는 함수도 아니고 메서드도 아님
- 위 코드는 `"cherry"`라는 값을 찾아서 해당 인덱스를 삭제

## ✅ 함수 밖에서 for문의 변수를 참조할 수 있는 이유

```python
for i in range(5):
    pass

print(i)  # 가능!
```

- 파이썬은 **블록 스코프가 아닌 함수 스코프** 사용
- `for`, `if`, `while` 등의 블록은 독립적인 스코프를 만들지 않음
- 따라서 블록 밖에서도 `i`를 참조할 수 있음

---

## ✅ 파이썬은 "참조 기반"이다

```python
a = [1, 2, 3]
b = a
b[0] = 99
print(a)  # [99, 2, 3]
```

- 변수는 값 자체가 아니라 **객체에 대한 참조(주소)를 저장**
- `id(a) == id(b)` → 두 변수는 같은 리스트 객체를 가리킴
- 하지만 `*` 문법은 포인터 아님! 헷갈리지 말 것!

## ✅ map과 pow를 함께 쓰는 반복 구조 예시

```python
from math import pow

numbers = [1, 2, 3]
arr1 = list(map(lambda x: pow(x, 2), numbers))
```

- `map()`은 반복문 없이 값 계산 가능
- `lambda`는 한 줄짜리 익명 함수 정의

---

## ✅ 리스트 제곱하는 다른 방법들

```python
# 리스트 컴프리헨션
arr1 = [x ** 2 for x in numbers]

# map + pow
arr1 = list(map(lambda x: pow(x, 2), numbers))

# 반복문
arr1 = []
for x in numbers:
    arr1.append(x ** 2)
```
