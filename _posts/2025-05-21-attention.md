# Attention Mechanism

LLM의 기본 구조가 되는 Transformer 모델에서 가장 중요한 것은 “Attention”이다. 처음에는 그저 “단어 간의 중요도를 계산하는 방법인가 보다\~” 하고 넘어갔지만, 제대로 뜯어보니 그 이상의 의미를 가지고 있었다. 이번 글에서는 Attention이 뭔지, 왜 그렇게 중요한지, 그리고 어떻게 계산되는지를 정리해봤다.

## Attention의 시작: Query, Key, Value

처음엔 왜 굳이 이름을 이렇게 붙였는지 어리둥절했지만, 알고 보면 꽤 직관적인 이름이었다.
간단히 정리하자면:

* **Query (Q)**: 지금 내가 알고 싶은 정보
* **Key (K)**: 문맥 속 단어들이 가지고 있는 특징
* **Value (V)**: 그 단어들에서 실제로 꺼내올 정보

말장난처럼 보이지만, 결국 이 세 가지는 각 단어를 표현한 벡터들이고, 우리가 얼마나 어떤 단어에 주목할지를 수치화하는 데 쓰인다.

## Attention 계산의 순서

하나씩 계산 과정을 따라가 보았다.

1. **Q와 K의 내적 (dot product)**
   → Q와 K를 곱하면 ‘얼마나 비슷한지’를 나타내는 값이 나온다.
   → 이걸 ‘유사도’ 혹은 ‘주의를 기울일 정도’를 뜻하는 score로 봄.

2. **스케일링**
   → 차원이 커질수록 값이 커져서 softmax에서 gradient가 작아지는 문제 때문에 √(dk)로 나눠준다.

3. **Softmax 적용**
   → attention score들을 확률처럼 바꿔서 어느 단어에 얼만큼 주목할지 결정.

4. **Value와 곱하기**
   → 마지막으로 각 단어의 value에 attention weight를 곱해, 정보가 강조되거나 줄어든다.

이 전체 과정을 한 줄로 요약하면:

```
Attention(Q, K, V) = softmax(QK^T / √d_k) * V
```

## 시각화로 감 잡기

노트북에서는 다양한 샘플 Q, K, V를 직접 정의하고, 이를 가지고 dot product를 구하는 과정이 코드로 잘 정리되어 있었다. 특히, 유사도를 시각화하고, attention weight가 어떻게 각 단어에 분포되는지 보는 부분이 직관적으로 이해를 도왔다.

→ 예를 들어, 특정 query가 ‘animal’일 때 ‘cat’, ‘dog’에 집중하고 ‘car’에는 관심이 없는 형태가 잘 나타났다.

## Multi-Head Attention: 하나로 부족해서 여럿 씀

한 번의 attention만으로는 단어 간 관계를 충분히 잡아내지 못하는 경우가 많다. 그래서 여러 개의 head를 둬서 서로 다른 관점에서 attention을 수행하게 했다. 이걸 Multi-head attention이라고 부른다.
즉, 서로 다른 공간으로 projection한 뒤 각각 attention을 수행하고, 그걸 다시 concat해서 종합하는 방식이다.

## 요약하며

Attention 메커니즘은 단순히 단어 간 중요도를 따지는 도구가 아니다. 이 구조 하나로 문맥 이해, 정보 강조, 그리고 연산 병렬화까지 이뤄낸다. Transformer의 힘은 결국 이놈의 정교한 계산에서 비롯된다.
