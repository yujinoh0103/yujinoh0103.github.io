## ✅ SQL 명령어 개요

- **DDL (Data Definition Language)**: 데이터베이스 구조 정의 (CREATE, ALTER, DROP 등)
- **DML (Data Manipulation Language)**: 데이터 조작 (SELECT, INSERT, UPDATE, DELETE 등)
- **DCL (Data Control Language)**: 권한 제어 (GRANT, REVOKE 등)
- **TCL (Transaction Control Language)**: 트랜잭션 제어 (COMMIT, ROLLBACK 등)

> `WHERE` 조건에서 `AND`가 `OR`보다 우선순위가 높음에 주의!

## ❌ ALTER TABLE 오류

```sql
ALTER TABLE students ADD COLUMN (
  students_id INT PRIMARY KEY,
  students_name VARCHAR(100),
  grade INT,
  score DECIMAL(5,2),
  attendance INT
);
```

- `ADD COLUMN`은 **하나의 컬럼만** 추가 가능 → 여러 컬럼은 각각 `ADD COLUMN` 필요
- `PRIMARY KEY`는 별도 지정 필요

✅ 수정 예시:

```sql
ALTER TABLE students
  ADD COLUMN students_id INT,
  ADD COLUMN students_name VARCHAR(100),
  ADD COLUMN grade INT,
  ADD COLUMN score DECIMAL(5,2),
  ADD COLUMN attendance INT;

ALTER TABLE students ADD PRIMARY KEY (students_id);
```

## ❌ HAVING 사용 오류

```sql
SELECT * FROM students GROUP BY HAVING grade;
```

- `HAVING`은 `GROUP BY` 이후 사용 가능
- 집계 함수와 함께 써야 함

✅ 수정 예시:

```sql
SELECT grade, COUNT(*) AS student_count
FROM students
GROUP BY grade
HAVING COUNT(*) >= 2;
```

---

## ❌ SELECT \* GROUP BY 사용 시 주의점

```sql
SELECT * FROM students GROUP BY grade;
```

⚠️ MySQL의 `ONLY_FULL_GROUP_BY` 모드에서는 오류 발생

- SELECT \*는 그룹화되지 않은 컬럼 포함 → 예측 불가능한 결과

✅ 집계 함수 사용 예시:

```sql
SELECT grade, AVG(score) AS avg_score
FROM students
GROUP BY grade;
```

✅ 비추천 해결 (학습용):

```sql
SET GLOBAL sql_mode=(SELECT REPLACE(@@sql_mode,'ONLY_FULL_GROUP_BY',''));
```

---

## ✅ ONLY_FULL_GROUP_BY란?

- `GROUP BY`에서 집계되지 않은 컬럼은 SELECT 불가 (에러 발생)
- 예측 불가능한 결과 방지

📌 예시:

```sql
-- ❌ 오류 발생
SELECT name, age FROM members GROUP BY age / 10;

-- ✅ 안전한 방식
SELECT FLOOR(age / 10) * 10 AS age_group, COUNT(*) AS count
FROM members
GROUP BY age_group;
```

## ❌ UNION, GROUP BY, 정렬 오류

```sql
SELECT c.customer_id, c.first_name, p.amount
FROM customer c
LEFT JOIN payment p ON c.customer_id = p.customer_id
UNION
SELECT c.customer_id, c.first_name, p.amount
FROM customer c
RIGHT JOIN payment p ON c.customer_id = p.customer_id
GROUP BY c.customer_id, c.first_name, c.last_name
ORDER BY total_paid DESC
LIMIT 10;
```

✅ 수정 예시:

```sql
SELECT
  c.customer_id,
  c.first_name,
  c.last_name,
  SUM(p.amount) AS total_paid
FROM customer c
LEFT JOIN payment p ON c.customer_id = p.customer_id
GROUP BY c.customer_id, c.first_name, c.last_name
ORDER BY total_paid DESC
LIMIT 10;
```

## ❌ JOIN 문법 오류

```sql
SELECT * FROM departments d, students s
LEFT JOIN s ON s.학과코드 = d.학과코드;
```

- `,`와 JOIN 혼용 불가
- LEFT JOIN 대상 순서 오류

✅ 수정 예시:

```sql
SELECT *
FROM students s
LEFT JOIN departments d ON s.학과코드 = d.학과코드;
```

## ✅ JOIN 시 컬럼 중복 해결법

### 방법 1: USING 사용 (컬럼명이 동일할 경우)

```sql
SELECT * FROM students s JOIN departments d USING (학과코드);
```

### 방법 2: AS로 별칭

```sql
SELECT
  s.학번,
  s.이름,
  s.학과코드 AS 학생_학과코드,
  d.학과코드 AS 학과_코드,
  d.학과명
FROM students s
JOIN departments d ON s.학과코드 = d.학과코드;
```

### 방법 3: 필요한 컬럼만 선택

```sql
SELECT s.*, d.학과명
FROM students s
JOIN departments d ON s.학과코드 = d.학과코드;
```

---

## ✅ 모든 컬럼 + 중복 제거

모든 컬럼을 가져오되 `학과코드` 중복만 제거하고 싶다면:

```sql
SELECT s.*, d.학과명
FROM students s
JOIN departments d USING (학과코드);
```

또는

```sql
SELECT s.*, d.학과명
FROM students s
JOIN departments d ON s.학과코드 = d.학과코드;
```

## ✅ FULL JOIN vs UNION

### FULL JOIN

- MySQL은 FULL JOIN 지원하지 않음

### UNION을 통한 구현:

```sql
SELECT s.*, d.학과명
FROM students s
LEFT JOIN departments d ON s.학과코드 = d.학과코드
UNION
SELECT s.*, d.학과명
FROM students s
RIGHT JOIN departments d ON s.학과코드 = d.학과코드;
```

### UNION vs UNION ALL

- `UNION`: 중복 제거
- `UNION ALL`: 중복 포함 (더 빠름)
