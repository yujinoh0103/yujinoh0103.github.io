# 📚 pandas 실습 - 그룹핑, 최대값 찾기, 인덱스 확인까지!

오늘은 `pandas`를 이용해 데이터프레임을 다루면서 여러 가지 실습을 진행했다. 특히 `groupby`, `idxmax`, 최대값 인덱스 찾기, 그리고 시각화까지 배워봤다.

## 1. `astype(str)`로 문자열 변환하기

처음에 데이터프레임의 어떤 열이 `int` 타입이라 `.str` 함수를 쓸 수 없었다. 그래서 `astype(str)`을 이용해 문자열로 변환했다.

```python
df['사용월'] = df['사용월'].astype(str)
```

- `.str.contains()` 같은 문자열 함수를 쓰려면 반드시 타입이 `str`이어야 한다.
- 만약 타입이 `int`, `float`면 `.str` 접근 자체가 불가능해서 `AttributeError`가 난다.

---

## 2. `sum` vs `transform('sum')` 차이

데이터를 그룹별로 합칠 때, `sum`과 `transform('sum')`은 엄연히 다르다.

- `sum`은 **그룹별로 한 줄만 남긴다**.
- `transform('sum')`은 **원래 데이터프레임 모양을 유지하면서 합계 값을 각 행에 넣어준다**.

```python
# sum 사용
df.groupby('호선명')['1달 총 이용객'].sum()

# transform('sum') 사용
df['호선별 총 이용객'] = df.groupby('호선명')['1달 총 이용객'].transform('sum')
```

**요약**:

- `sum` → 결과가 압축된다 (그룹별 한 줄)
- `transform('sum')` → 결과가 원래 행 수만큼 유지된다

---

## 3. `groupby` 후 시각화하기 (seaborn)

데이터를 그룹핑해서 합계 구한 뒤, `seaborn`으로 시각화도 했다.

```python
연도별합계 = df.groupby('사용연도')['총 승차인원'].sum().reset_index()

import matplotlib.pyplot as plt
import seaborn as sns

plt.figure(figsize=(10, 6))
sns.lineplot(data=연도별합계, x='사용연도', y='총 승차인원')
plt.xticks(rotation=45)
plt.title('연도별 총 승차인원 변화')
plt.ylabel('총 승차인원')
plt.xlabel('사용연도')
plt.tight_layout()
plt.show()
```

**주의할 점**:

- `sns.plot()`은 없음! `sns.lineplot()`이나 `sns.barplot()` 등을 써야 한다.

---

## 4. 가장 점검을 많이 한 월 찾기 (`idxmax`)

`groupby`로 월별 점검 수를 세고, 가장 점검이 많은 달을 찾을 때 `idxmax()`를 썼다.

```python
monthly_counts = df.groupby(df['점검일자'].dt.month).size()

most_frequent_month = monthly_counts.idxmax()
most_frequent_count = monthly_counts.max()
```

- `idxmax()`는 **가장 값이 큰 인덱스**를 반환한다.
- `max()`는 **가장 큰 값** 자체를 반환한다.

**정리**:
| 함수 | 반환 결과 |
|:---|:---|
| `idxmax()` | 가장 큰 값을 가지는 **인덱스** |
| `max()` | 가장 큰 값 **자체** |

---

## 5. 최대값을 가지는 모든 인덱스 찾기

만약 "가장 많이 점검된 달이 여러 개면?" 이런 경우를 대비해, **여러 인덱스**를 한 번에 뽑고 싶을 때는 이렇게 한다:

```python
# 가장 큰 값
most_frequent_count = monthly_counts.max()

# 그 값과 같은 인덱스들 찾기
most_frequent_months = monthly_counts[monthly_counts == most_frequent_count].index
print(most_frequent_months)
```

이렇게 하면 "최대 점검 수"를 가진 월들이 **여러 개**라도 다 찾을 수 있다.

---

## 6. 인덱스 전체 확인하기

그룹핑 결과나 다른 시리즈를 다루다가, 인덱스 전체를 보고 싶을 땐 `.index`를 사용하면 된다.

```python
print(monthly_counts.index)
```

- `.index`를 쓰면 인덱스만 따로 볼 수 있다.
- 만약 인덱스를 리스트로 변환하고 싶으면 `list(monthly_counts.index)`를 쓰면 된다.

---

# ✨ 마무리

오늘 배운 핵심은:

- `astype(str)` 변환은 `.str` 쓰기 위해 필수
- `transform('sum')`은 원본 모양 유지
- `idxmax()`는 최대값 가진 인덱스를 찾는다
- `max()`는 최대값 자체를 준다
- 같은 최대값이 여러 개 있을 수 있다 → 조건으로 뽑는다
- `.index`로 인덱스만 따로 확인 가능

**앞으로 그룹핑하거나 최대값 찾을 때 실수하지 않게 기억해야겠다!**
