## 1. 평균 점수 구하기에서의 `sum` 오류

```python
grades = {
    '국어': 80,
    '영어': 75,
    '수학': 55,
}

sum = 0
for score in grades:
    sum += grades[score]

print(sum / len(grades))  # 출력: 70.0
```

> ❗ 주의: `sum`이라는 이름은 **내장 함수** 이름이라 피하는 게 좋다.

```python
avg = sum(grades.values())  # ⚠️ 이 때 sum이 int면 TypeError 발생
```

- 내가 앞에서 `sum = 0` 으로 덮어썼다면 `sum()`을 함수로 다시 못 쓴다.
- 해결 방법: `sum`이라는 변수명을 피하거나, `del sum`으로 제거하고 다시 사용한다.

## 2. 리스트 역순 정렬에서 `.sort()` 반환값

```python
a = [1, 3, 5, 4, 1]

sorted = a.sort()
reSorted = a.sort(reverse=True)
print(sorted, reSorted)  # 둘 다 None!
```

- `.sort()`는 **리스트를 직접 바꾸고**, 반환값은 `None`이다.
- 정렬된 리스트를 변수에 담고 싶다면 `sorted()`를 사용하자.

```python
a = [1, 3, 5, 4, 1]
a.sort(reverse=True)
print(a)  # [5, 4, 3, 1, 1]
```

## 3. 리스트를 문자열로 만들기

```python
b = ['Life', 'is', 'too', 'short']
result = ' '.join(b)
print(result)  # Life is too short
```

- `'구분자'.join(리스트)`를 사용해서 문자열로 만들 수 있다.

## 4. 딕셔너리 키 타입 오류

```python
d = {}
d['name'] = '홍길동'        # OK
d[('a',)] = "홍길동"        # OK (튜플은 해시 가능)
# d[[1]] = "홍길동"         # ❌ 오류 발생 (리스트는 해시 불가)
d[250] = "홍길동"           # OK
```

- 리스트는 mutable하기 때문에 딕셔너리 키로 사용할 수 없다.

## 5. 리스트 중복 제거: `set()` 사용법

```python
f = [1, 1, 1, 2, 2, 3, 3, 3, 4, 4, 5]

fSet = set(f)
g = list(fSet)
print(g)  # [1, 2, 3, 4, 5] (순서는 보장 안됨)
```

- `set()`은 중복을 제거하지만 순서가 섞일 수 있다.
- 순서를 유지한 채 중복 제거하고 싶다면 `dict.fromkeys(f)` 또는 `collections.OrderedDict` 사용.

## 6. `chr()`로 이상한 문자 출력되는 이유

```python
for i in range(1, 4):
    for j in range(1, 4):
        print(f"({i},{chr(j)})")
```

### ❗ 문제:

- `chr(1)`, `chr(2)`, `chr(3)`은 **제어 문자**라서 이상하게 보인다.

### ✅ 해결:

```python
for i in range(1, 4):
    for j in range(65, 68):  # 65='A'
        print(f"({i},{chr(j)})")
```

## 7. 리스트 순회 중 `pop()`의 위험성

```python
for x in arr:
    arr.pop()  # ❌ 위험: 리스트 길이 바뀌면서 순회 꼬임
```

### 해결 방법:

- `for x in arr[:]`처럼 **복사본으로 순회**
- 또는 `while`문으로 인덱스를 직접 관리

## 8. `summaryRanges` 함수 구현 중 꼬임 주의

```python
if i = len(nums - 1):  # ❌ 잘못된 비교 문법
```

- `=`는 **할당**, `==`는 **비교**
- `len(nums - 1)`도 말이 안 됨 → `len(nums) - 1`로 써야 함

또한 반복 중 `pop()` 등의 연산으로 리스트 길이가 바뀌면 `for`문은 불안정할 수 있다. 이럴 땐 `while`문이 더 적절하다.

## 9. `copy.copy()`로 리스트 복사했는데 반영 안 되는 이유

```python
import copy

class Solution:
    def removeElement(self, nums: List[int], val: int) -> int:
        test = []
        k = 0
        for x in nums:
            if x != val:
                test.append(x)
                k += 1

        nums = copy.copy(test)  # ⚠️ 이렇게 복사해도 외부 nums에는 반영 안 됨
        return len(nums) - k
```

### ❗ 문제:

- `nums = copy.copy(test)`를 해도 함수 외부에서 `nums`가 바뀌지 않는다.
- 왜냐하면 **리스트 복사한 결과를 `nums`라는 새로운 지역 변수에 할당했기 때문**.

### ✅ 해결:

- 직접 `nums` 리스트를 수정해야 한다.

```python
# nums 내용을 직접 수정
nums[:] = test
```

이렇게 하면 `nums` 리스트 객체 자체는 그대로 유지되면서, 그 내부 내용만 바뀌기 때문에 함수 외부에도 반영된다.
