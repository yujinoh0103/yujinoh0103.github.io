## 🚨 useSafeAreaInsets() 에러 로그 분석

```js
// styles.js

import { StyleSheet, StatusBar } from "react-native";
import { useSafeAreaInsets } from "react-native-safe-area-context";

export const styles = StyleSheet.create({
  container: {
    paddingTop: StatusBar.currentHeight || insets.top, // ❌ 오류 발생 지점
    flex: 1,
    backgroundColor: "#fff",
    alignItems: "center",
    justifyContent: "center",
  },
});
```

### ❗ 문제 요약

- `useSafeAreaInsets()`는 **React Hook**이므로 **함수형 컴포넌트 내부**에서만 호출해야 함.
- 위 코드처럼 **컴포넌트가 아닌 외부 파일(styles.js 등)** 에서 실행하면 **React가 감지하지 못하고 오류 발생**.

### ✅ 해결 방법

Hook은 **컴포넌트 내부**에서 호출해야 하며, `insets.top`은 `SafeAreaView`의 `style`에 직접 적용해야 함.

```js
import React from "react";
import { View, Text, StyleSheet, StatusBar } from "react-native";
import {
  SafeAreaProvider,
  SafeAreaView,
  useSafeAreaInsets,
} from "react-native-safe-area-context";

export default function App() {
  return (
    <SafeAreaProvider>
      <SafeAreaComponent />
    </SafeAreaProvider>
  );
}

function SafeAreaComponent() {
  const insets = useSafeAreaInsets();

  return (
    <SafeAreaView style={[styles.container, { paddingTop: insets.top }]}>
      <StatusBar
        barStyle="dark-content"
        translucent
        backgroundColor="transparent"
      />
      <Text>Hello, Safe Area!</Text>
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: "#fff",
    alignItems: "center",
    justifyContent: "center",
  },
});
```

## 🌙 다크 모드 vs ☀️ 라이트 모드 구현 예제

```js
import React, { useState } from "react";
import { View, Text, Switch, StyleSheet, useColorScheme } from "react-native";

export default function App() {
  const systemTheme = useColorScheme();
  const [isDarkMode, setIsDarkMode] = useState(systemTheme === "dark");

  const toggleTheme = () => {
    setIsDarkMode((prev) => !prev);
  };

  return (
    <View
      style={[
        styles.container,
        isDarkMode ? styles.darkBackground : styles.lightBackground,
      ]}
    >
      <Text
        style={[styles.text, isDarkMode ? styles.darkText : styles.lightText]}
      >
        {isDarkMode ? "\ud83c\udf19 다크 모드" : "\u2600\ufe0f 라이트 모드"}
      </Text>
      <Switch value={isDarkMode} onValueChange={toggleTheme} />
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    alignItems: "center",
    justifyContent: "center",
  },
  lightBackground: {
    backgroundColor: "#ffffff",
  },
  darkBackground: {
    backgroundColor: "#121212",
  },
  lightText: {
    color: "#000000",
  },
  darkText: {
    color: "#ffffff",
  },
});
```

## ⚙️ StyleSheet.create()와 동적 스타일링 혼합하기

```js
const styles = (isDarkMode) =>
  StyleSheet.create({
    container: {
      flex: 1,
      alignItems: "center",
      justifyContent: "center",
      backgroundColor: isDarkMode ? "#121212" : "#ffffff",
    },
    text: {
      fontSize: 18,
      fontWeight: "bold",
      color: isDarkMode ? "#ffffff" : "#000000",
    },
  });

// 사용 시
<View style={styles(isDarkMode).container}>
  <Text style={styles(isDarkMode).text}>
    {isDarkMode ? "\ud83c\udf19 다크 모드" : "\u2600\ufe0f 라이트 모드"}
  </Text>
</View>;
```

## 🚀 최적화를 위한 useMemo() 적용

```js
import React, { useState, useMemo } from "react";
import { View, Text, Switch, useColorScheme } from "react-native";

export default function App() {
  const systemTheme = useColorScheme();
  const [isDarkMode, setIsDarkMode] = useState(systemTheme === "dark");

  const toggleTheme = () => {
    setIsDarkMode((prev) => !prev);
  };

  const dynamicStyles = useMemo(
    () => ({
      container: {
        flex: 1,
        alignItems: "center",
        justifyContent: "center",
        backgroundColor: isDarkMode ? "#121212" : "#ffffff",
      },
      text: {
        fontSize: 18,
        fontWeight: "bold",
        color: isDarkMode ? "#ffffff" : "#000000",
      },
    }),
    [isDarkMode]
  );

  return (
    <View style={dynamicStyles.container}>
      <Text style={dynamicStyles.text}>
        {isDarkMode ? "\ud83c\udf19 다크 모드" : "\u2600\ufe0f 라이트 모드"}
      </Text>
      <Switch value={isDarkMode} onValueChange={toggleTheme} />
    </View>
  );
}
```

## ✅ 동적 스타일링 적용 방식 요약

| 방법                 | 장점                   | 단점                      |
| -------------------- | ---------------------- | ------------------------- |
| 인라인 스타일        | 빠르고 간단            | 코드 중복 많아짐          |
| StyleSheet 함수 사용 | 구조적, 코드 정리 용이 | 매 호출 시 함수 실행 필요 |
| useMemo 최적화       | 렌더링 최적화          | 약간 복잡함               |
